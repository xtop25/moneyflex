NOVA WALLET — демо-интерфейс крипто-кошелька (Windows)
=======================================================

Это пустышка/макет: реальных денег, блокчейна и сети внутри нет.
Все цифры вводишь сам в настройках. Не используй это, чтобы
кого-то обманывать или выманивать деньги — только для себя/скринов.

---------------------------------------------------
БЫСТРЫЙ ЗАПУСК (без сборки, 2 секунды)
---------------------------------------------------
Двойной клик по NovaWallet.bat
Откроется отдельное окно 1280x800 без адресной строки и вкладок —
выглядит как обычная программа. Для скринов жми F11 (полный экран).

Если Chrome/Edge не найден — откроется CryptoWallet.html в браузере
по умолчанию (тогда лучше нажать F11).

---------------------------------------------------
СБОРКА НАСТОЯЩЕГО .EXE
---------------------------------------------------
1. Установи Python 3 с python.org
   (галочка "Add python.exe to PATH" обязательна).
2. Двойной клик по build_exe.bat — он сам поставит PyInstaller
   и соберёт файл.
3. Готовый файл: dist\NovaWallet.exe — один самодостаточный файл,
   можно переносить куда угодно, иконка и запуск как у обычной проги.

(Собрать exe можно только на самой Windows — поэтому bat-скрипт.)

---------------------------------------------------
НАСТРОЙКИ (PIN: 0000)
---------------------------------------------------
Шестерёнка справа сверху или пункт "Настройки" в меню слева →
вводишь 0000 → откроется редактор:

- Название кошелька и инициал аватарки
- Валюта: USD / EUR / UAH / GBP
- Изменение за 24ч в % (зелёный/красный бейдж)
- "Подогнать общий баланс под сумму": пишешь, например, 25000 →
  "Пересчитать" → все монеты пересчитаются пропорционально
- Таблица монет: галочка (показывать/скрыть), тикер, количество, цена
- "+ Добавить монету", крестик — удалить
- Известные тикеры (BTC, ETH, SOL, USDT, XRP, ADA, LINK, LTC, DOGE,
  TRX, BNB, TON, MATIC, AVAX) сами подхватывают имя, символ и цвет
- "Сохранить" — настройки запоминаются между запусками
- "Сброс" — вернуть значения по умолчанию

---------------------------------------------------
ЧТО ЕСТЬ В ИНТЕРФЕЙСЕ
---------------------------------------------------
- Портфель: общий баланс, +% за 24ч, доступно / в стейкинге / лидер дня
- Список активов: монета, количество, сумма в валюте, курс, 24ч
- Клик по монете: детальная страница + фейковые транзакции
- Кнопки Отправить / Получить (с QR и адресом), Обмен, История
- Поиск по активам
- Никаких графиков — как и просил

ESC закрывает любое окно.
